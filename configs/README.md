# Registration configurations

The runnable version-1 template is [../examples/synthetic/package/registration.json](../examples/synthetic/package/registration.json). It contains real generated digests rather than placeholders, and can be verified against its accompanying evidence immediately.

For another experiment, export a new registration with real row identities, metadata, weights, both arms' requirements, digests and prediction paths. Do not mechanically copy synthetic expectations or hash new observations after inspecting outcomes and call them preregistered requirements. See [schema](../docs/evidence_schema.md).
