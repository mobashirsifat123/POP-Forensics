# Reproducibility boundaries

| Material | Role | Public release treatment |
|---|---|---|
| Current manuscript | Protocol and scientific findings | Metadata and newly written explanation; PDF/figures not redistributed |
| Original historical validator, 58-scope matrix, archive catalog | Historical scope decisions | Unavailable; never fabricated or reconstructed |
| Earlier internal NumPy checker and 16-case test | Author-designed software-conformance evidence | Inspected locally; not copied or relabeled as historical validator |
| New popverify implementation and 16-case fixtures | Versioned reference software | Included under MIT; independently written, same decision priority |
| Saved prediction rescoring and optimizer-log receipts | Analyses of historical outputs | Inspected for methodology; not redistributed or claimed rerun here |
| Raw data, historical predictions and pretrained/model weights | Restricted or review-dependent research resources | Excluded |

Run the committed synthetic package, regenerate it in a fresh directory, run unittest and build/install the wheel. The synthetic generator is deterministic on the tested Python environment; floating-point bytes across runtimes need not be identical. Registered digests bind the actual generated bytes. The static package and its registration are illustrative, not independent preregistration evidence.

The paper's historical 0 PASS/7 FAIL/51 UNRESOLVED counts cannot be independently reproduced from this software. Neither the original forensic experiments nor the prior five-seed conformance experiment was rerun during this release. New tests do not certify lost historical evidence. No GPU work is needed or performed.

For an actual study freeze registration before fitting/selection, retain full trustworthy logs and artifacts, compute both byte/RGB content registries, export independent predictions in registered row order and publish appropriately licensed receipts with access instructions. A replay of saved arithmetic alone cannot establish cache state or optimization at historical execution time.
