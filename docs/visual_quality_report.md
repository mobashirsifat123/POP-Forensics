## Original visual assets

The logo, banner, social-preview source and five diagrams are original SVG artwork generated by `scripts/generate_visuals.py`. The receipt diagram reads the actual generated PASS receipt and abbreviates hashes for display. Full hashes remain in the JSON. No diagrams imply automatic training instrumentation or model execution.

The site uses system fonts, high-contrast navy/blue/teal text, text-labeled gate/outcome distinctions, visible keyboard focus, responsive layouts and reduced-motion handling. Larger diagrams can scroll horizontally within their containers on small screens. These are targeted checks, not a comprehensive accessibility certification.

Material's automatic repository-statistics request was replaced by a static source link, avoiding its request for a nonexistent latest stable release. The project currently has experimental prereleases. The local docs homepage produced no console errors after this change; GitHub's own telemetry is outside this site's control.
