# Quickstart

Run from the repository root after installation:

```sh
python examples/synthetic/generate.py output/demo
popverify validate output/demo/registration.json
popverify verify output/demo/registration.json output/demo/evidence.json --json
```

The generator writes the registration before its two-arm 40-update logistic fits. It then exports counters, parameters, target observations, completed input cache and read-back reconstructed predictions. It uses deterministic standard-library CPU arithmetic. It refuses an existing destination. This new example differs from the paper's five-seed NumPy implementation experiment.

A static package is provided under `examples/synthetic/package/`. It is an inspectable fixture generated by the same script, not an independent validation dataset. To demonstrate outcomes safely, copy it into a new directory and change `baseline-delta` in `evidence.json` to zero (FAIL), or remove `complete` (UNRESOLVED). Making both changes yields FAIL.

```python
from popverify import verify

receipt = verify(
    "examples/synthetic/package/registration.json", "examples/synthetic/package/evidence.json"
)
assert receipt["outcome"] == "PASS"
```

`--output receipt.json` writes a full receipt with exclusive creation; existing files are never overwritten. Parent output directories must already exist. JSON stdout is available with `--json`. Exit codes are documented in the README. Invalid registration raises ValueError in the API; missing evidence returns a scoped UNRESOLVED receipt.
